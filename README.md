# Simulator

Today's NBA games in America/Chicago. Simulate draws 10,000 independent games in the browser from a committed rate card.

This is a simulator, not a betting ticket.

The NFL switch shows today's and yesterday's games, then the rest of the NFL week, with each team's record. Once that week has no later games, the next scheduled week appears. Each game is simulated 10,000 times from this season's box scores and its injury report. Simulate plays it on the page, as the NBA Simulate does, and opens its box score: the projected score and win chance, the margin and total charts, a total and margin line check, and passing, rushing and receiving tables for both sides with each player's photo and 10th-to-90th range. A player's name opens his sheet, as an NBA name does: his expected line and its spread, and a checker that reads any line against the same 10,000 games. The win chances, ranges and player means are calibrated walk-forward on earlier weeks, which the page reports. No market line is used. Without enough box scores it falls back to a score-only Elo.

The esports switch projects each player: CS2 kills and headshots over maps 1-2 from his kills and headshots per round, Dota 2 and League of Legends kills and assists per game. Each projection has a 10th-to-90th range calibrated on the same players' earlier games, with the plain average beneath it and what he did once the game is played. An upcoming CS2 match lists the five players on each side who played most recently.

NBA bets of the day sits above Games and Projections: the strongest player prop and game spread left on today's slate, read from the same 10,000 simulations as the box scores and taken at the best tracked pregame price. A prop must clear the checks the projections use, including a live-graded record of similar leans beating the posted price; a spread must clear the same edge and noise bars against the ESPN scoreboard's current spread. Each pick shows its book, price, when that price was checked, the model's chance, the break-even and the estimated return, and what its grade rests on. When nothing qualifies, the panel says why. A price drops off six hours after it was checked or at the tip. No pick is a sure thing.

Lineups lets you rule any player in or out for one game before simulating. Your calls stay in your browser and never change the published card.

The current model and its limits are described in [MODEL_SPEC.md](MODEL_SPEC.md). The `MODEL_AUDIT_*` reports are historical snapshots.

Projections is a board of player cards: every game still to play, or one game, for the stat picked at the top. Each card shows the player's photo, his projection, the posted line, his simulated spread against it, and the model chance on each side; tapping it opens his chart, game log and floor splits. A defense filter keeps soft or tough matchups at each player's position. Projections also holds the Defense view (tonight's defenses ranked by position for the stat, where a number opens the players who face it). The page no longer shows Matchups. Projections compares each simulation with the posted over/under line for that player and shows how comparisons like it have settled. Every comparison is logged before its game tips and graded from the final box score, so the record under the list is measured, not claimed.

Run `npm test`, `npm run typecheck`, `npm run build`, `npm run validate-artifact`, and `npm run validate-privacy` to verify. `GENERATOR_SHA=pending npm run rate-card` explicitly builds local data; publishing from a committed source uses that source SHA instead of pending. This refreshes the permitted source data. `npm run sanity` reports seeded 10,000-draw projections; `npm run walk-forward` scores the team model out of sample on every game since January 2026; `npm run replay` rebuilds archived pre-tip cards with the current code and scores them against results and archived lines; `npm run backtest` runs the chronological diagnostic. The backtest does not certify calibration or market accuracy. `npm run picks` compares the published card with posted lines, logs and grades them, and writes `public/data/picks.json`; `node --experimental-strip-types scripts/publish-sims.ts dist/data` draws each game of the built card the way the deploy does and writes the files the page reads in place of a phone's own draws. `npm run picks:backfill` replays archived pre-tip cards against the lines posted at the time (`BACKFILL_REBUILD=1` after a model change).
